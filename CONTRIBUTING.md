# Contributing

This project does not accept contributions. Pull requests will be closed, and
feature requests will not be taken up.

It is a personal project that publishes the code and data behind the charts at
[jameswarrick.com/money/trends/](https://www.jameswarrick.com/money/trends/).
The purpose is transparency: anyone can inspect how each series is computed,
where its inputs come from, and which terms are recorded for those inputs.

You are welcome to fork and modify the MIT-licensed code. Data has separate,
per-source terms. See
[Sources and licences](https://nimbleox.github.io/market-trends/sources/)
before reusing or redistributing it.

The [Development guide](https://nimbleox.github.io/market-trends/development/)
covers setup, tests, the documentation build, and how to add sources or series
in a fork.
